# Release 0.12.12 — compatibilidade PostgreSQL em contas

**Status:** candidata; publicação pendente.

## Correções

- Colunas Better Auth camelCase agora são identificadas com aspas nas consultas PostgreSQL de cadastro, perfil e manutenção de credenciais administrativas.
- A Fase 4 revelou dois sintomas no ambiente isolado: cadastro retornava erro após criar a conta, e o provisionador administrativo falhava ao conferir a credencial. Ambos decorriam de identificadores sem aspas.
- Não há alteração de schema, contagem de dados, fluxo de reservas, segredo, SMTP ou configuração Turnstile.

## Gate de publicação

- A correção precisa ser compilada e conferida em PostgreSQL descartável.
- Criar backup PostgreSQL novo, copiar para este computador, validar checksum e ensaiar restauração isolada antes de atualizar a VPS.
- Após publicação, registrar health web/worker/PostgreSQL, heartbeat, contagens agregadas e preservar a release anterior para retorno.
