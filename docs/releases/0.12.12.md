# Release 0.12.12 — compatibilidade PostgreSQL em contas

**Status:** publicada na VPS em 04/11/2026.

## Correções

- Colunas Better Auth camelCase agora são identificadas com aspas nas consultas PostgreSQL de cadastro, perfil e manutenção de credenciais administrativas.
- A Fase 4 revelou dois sintomas no ambiente isolado: cadastro retornava erro após criar a conta, e o provisionador administrativo falhava ao conferir a credencial. Ambos decorriam de identificadores sem aspas.
- Não há alteração de schema, fluxo de reservas, segredo, SMTP ou configuração Turnstile.

## Retorno

Como não houve alteração de schema, a release 0.12.11 permanece elegível para rollback. Execute na VPS como `hub`:

```sh
release=/opt/hub-turismo/release-0.12.11
ln -s "$release" /opt/hub-turismo/current.rollback &&
  mv -Tf /opt/hub-turismo/current.rollback /opt/hub-turismo/current
cd "$release"
COMPOSE_PROJECT_NAME=hub-turismo docker compose --env-file infra/vps.env -f infra/compose.vps.yaml up -d --no-deps web booking-email-worker
```

Esse retorno recria somente `web` e `booking-email-worker`. Não recrie nem remova o volume PostgreSQL.
