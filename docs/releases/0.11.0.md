# Release 0.11.0 — Preflight local da VPS

**Registro atualizado:** 14/10/2026  
**Status:** validada localmente; não publicada.

## Resultado

O validador de ambiente VPS passa a ter o comando documentado `npm run check:vps-env`. Ele confere `infra/vps.env`, compara a etiqueta da imagem com o pacote e não imprime valores secretos.

## Escopo

- Registra `check:vps-env` no package e passa ao validador o arquivo protegido e `package.json`.
- Mantém as verificações de domínio HTTPS, chaves Turnstile, versão, credenciais PostgreSQL distintas, força das senhas, opções SMTP e permissões do arquivo em sistemas POSIX.
- Testa configuração válida usando arquivo temporário, rejeição de domínio de exemplo e versão divergente, e ausência de segredos na saída.
- A orientação de deploy mantém também a validação isolada em container e a checagem de permissões no servidor Linux.
- Sem migration, alteração dos dados oficiais, configuração Docker, credenciais ou envio de e-mail.

## Compatibilidade e retorno

A versão 0.11.0 é compatível com o mesmo schema e a imagem 0.10.0. O retorno ao binário 0.10.0 remove somente o comando de preflight do package; não modifica banco nem ambiente.

## Verificação

- `npm test`: 59 aprovados, 0 falhas e 3 ignorados (os testes PostgreSQL não foram configurados nesta rodada; backup/restauração requer bash POSIX).
- `npm run typecheck`, `npm run lint`, `npm run check:version`, `npm run check:vps-release`, `npm run check:architecture` e `npm run format:check` passaram.
- `npm run check:vps-env` passou com fixture local sintética; testes confirmaram rejeição de domínio de exemplo e versão divergente e ausência de segredos na saída.
- `docker compose --env-file infra/vps.env.example -f infra/compose.vps.yaml config --quiet` passou. Esta release não altera a lógica do runtime web.
- `docker build --tag hub-turismo-amazonas:0.11.0 --build-arg SITE_URL=http://127.0.0.1:3005 .` passou.
- Compose descartável com a configuração de exemplo confirmou `/api/health` como `{"status":"ok","version":"0.11.0","database":"postgresql"}`. Os três serviços iniciaram e ficaram saudáveis; containers, rede e volume temporários foram removidos.
- Revalidação dos dados oficiais: `npm run db:verify-snapshot -- data/hub.sqlite backups/hub-pre-vps-20261014.sqlite` confirmou 24 tabelas, 5.480 linhas e fingerprint `893259276d3d3c085eea4f413cf013fb4e208c239f40206e00106e1f9fb71b1c`. A prévia e a aplicação completa do importador passaram em PostgreSQL 18.6 descartável com o schema 0.11.0: 2 contas, 2.727 auditorias, 6 importações Cadastur, 2.721 entradas Cadastur e 1 imagem local; não há empresas, reservas ou conteúdo editorial nesta origem. Sessões e estado operacional de e-mail não foram transferidos. O Compose e seu volume foram removidos após a validação.
- Não houve acesso à VPS, alteração da base oficial, envio de e-mail ou publicação.

## Publicação

Ainda não publicada. A implantação continua pendente da organização do acesso SSH à VPS, configuração do domínio e homologação do SMTP real.
