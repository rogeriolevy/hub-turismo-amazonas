## Retorno

Execute na VPS como `hub` somente se a saúde ou os dados divergirem:

```sh
release=/opt/hub-turismo/release-0.12.12
ln -s "$release" /opt/hub-turismo/current.rollback-0.12.13 &&
  mv -Tf /opt/hub-turismo/current.rollback-0.12.13 /opt/hub-turismo/current &&
  COMPOSE_PROJECT_NAME=hub-turismo docker compose --project-name hub-turismo \
    --env-file "$release/infra/vps.env" \
    -f "$release/infra/compose.vps.yaml" \
    up -d --no-deps --no-build web booking-email-worker
```

Esse procedimento troca `current` e atualiza somente web/worker. Não recrie PostgreSQL, não altere o volume e não reimporte SQLite.
