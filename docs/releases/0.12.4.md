# Candidata 0.12.4 — Poda das dependências do runtime

**Registro atualizado:** 16/10/2026  
**Status:** candidata local superada pela 0.12.5; não publicada.

## Resultado esperado

A imagem de produção contém apenas dependências de produção travadas no lockfile, sem ferramentas de lint e sua cadeia vulnerável de expansão de padrões.

## Escopo

- Depois da compilação Next.js, copia o lockfile para o standalone e remove somente pacotes traçados cuja entrada exata no lockfile está marcada como dependência exclusiva de desenvolvimento.
- Adiciona `scripts/prepare-standalone-runtime.mjs`, que confere versões de toda a árvore traçada contra o lockfile, preserva as dependências diretas de produção e falha se encontrar `eslint-config-next`, `@next/eslint-plugin-next`, `fast-glob`, `micromatch` ou `braces` no runtime.
- Remove do manifesto standalone as dependências de desenvolvimento e o lockfile com entradas dev depois da conferência.
- Não altera dependências, permissões, APIs, regras de negócio, schema ou dados do banco.
- A primeira embalagem desta candidata usava `npm prune` e foi descartada: expandiu o pacote Next.js traçado de 29 MB para 203 MB e aumentou o tamanho da imagem em cerca de 228 MB. A implementação atual preserva os arquivos traçados e remove apenas o que o lockfile marca como desenvolvimento.

## Segurança e verificação

- `node --check scripts/prepare-standalone-runtime.mjs`, `npm run typecheck`, `npm run check:architecture` (74 entradas de cliente), `npm run check:version`, `npm run check:vps-release`, Prettier e ESLint do guard passaram.
- O build Docker compilou Next.js e TypeScript. Antes da etapa runtime, o guard confere todas as versões do trace e as 31 dependências diretas de produção; a inspeção da imagem confirmou usuário `node`, ausência de `devDependencies`, lockfile de build e dos cinco pacotes da cadeia de lint.
- `npm audit` reporta cinco alertas altos restritos à árvore de desenvolvimento; `npm audit --omit=dev` não encontrou vulnerabilidades em produção. A candidata remove do runtime os pacotes sinalizados; a auditoria completa permanece registrada para futura atualização de ESLint quando houver correção compatível. O aviso atual não lista versão corrigida de `braces` e o downgrade sugerido pelo npm é incompatível.
- A suíte comportamental não foi executada nesta entrega. Não há migração de banco nem alteração de dados.
- A candidata só poderá ser transferida/publicada depois de configurar e validar a cópia externa do backup PostgreSQL por ensaio independente de restauração.
