# Candidata 0.12.6 — Auditoria reproduzível do pacote VPS

**Registro atualizado:** 16/10/2026  
**Status:** candidata local; não publicada.

## Escopo

- Adiciona `scripts/verify-vps-release-bundle.mjs` e `npm run verify:vps-release-bundle -- <pasta>` para validar um pacote de release local sem transferi-lo.
- Confere o conjunto de arquivos esperado, os hashes e tamanhos do manifesto e dos sidecars, o manifesto de fontes e cada arquivo contido no ZIP.
- Confere que a imagem local corresponde à identidade registrada no pacote e executa novamente a verificação runtime em container sem rede, somente leitura, sem capabilities e sem elevação de privilégios.
- Mostra explicitamente se o gate de cópia externa do backup continua pendente; a verificação de integridade não aprova a publicação por si só.
- Não altera schema, regras de negócio, dados SQLite/PostgreSQL, serviço em execução ou configuração da VPS.

## Verificação

- Checks de versão, release VPS, arquitetura, formatação, TypeScript, lint dos scripts de release e configuração Compose passaram.
- Build Linux a partir do snapshot-fonte passou; a imagem runtime 0.12.6 ficou abaixo do limite de 550 MB, com usuário `node`, 31 dependências diretas e 275 pacotes runtime.
- O pacote local passou pela conferência de hash, manifesto, 507 arquivos internos do ZIP e identidade da imagem Docker. A verificação runtime foi executada em container sem rede, somente leitura, sem capabilities e sem elevação de privilégios.
- O `npm ci` reportou cinco vulnerabilidades altas na árvore total; `npm audit --omit=dev --audit-level=high` encontrou zero vulnerabilidades na árvore de produção.
- A suíte comportamental não foi executada nesta entrega.
- A publicação permanece pendente de receber e validar uma cópia externa do backup por ensaio independente de restauração.
