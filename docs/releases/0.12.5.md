# Candidata 0.12.5 — Validação da imagem runtime na CI

**Status atualizado:** substituída pela candidata 0.12.6; não publicar este pacote.

**Registro atualizado:** 16/10/2026  
**Status:** candidata local; não publicada.

## Resultado esperado

A CI valida o conteúdo e o tamanho da imagem Docker que será transferida para a VPS, além de verificar que o usuário do processo não é root.

## Escopo

- Adiciona `scripts/verify-vps-runtime-image.mjs` e `npm run verify:vps-runtime-image` para inspecionar a tag correspondente à versão atual.
- Verifica versão da aplicação, usuário `node`, dependências de produção presentes, ausência de `devDependencies` e lockfile de build, e ausência da cadeia de lint vulnerável.
- Impõe um limite de 550.000.000 bytes para a imagem; exceder o limite encerra a CI com erro para revisão.
- Executa a verificação na CI depois da construção da imagem Docker da VPS.
- Mantém Python, `make` e `g++` apenas no estágio de build para compilar `better-sqlite3` se o binário pré-compilado estiver indisponível; essas ferramentas não entram no runtime.
- Não altera API, regras de negócio, schema ou dados.

## Verificação

- O build e a execução local do verificador registram a imagem candidata 0.12.5; a execução remota no GitHub Actions depende de Actions habilitado no repositório.
- A suíte comportamental não foi executada nesta entrega.
- A candidata só poderá ser transferida/publicada depois de configurar e validar a cópia externa do backup PostgreSQL por ensaio independente de restauração.
